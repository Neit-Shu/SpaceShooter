# Космический шутер — прототип для Unity

Простая 2D-аркада: корабль двигается и стреляет, враги падают сверху, есть счёт, жизни, рекорд и перезапуск. Всё собирается из кода: спрайты рисуются программно, префабы и настройка сцены не нужны.

## Перенос в Unity

1. Создайте пустой проект: Unity Hub → New project → «2D (Built-In Render Pipeline)» или «Universal 2D». Подойдут и 3D-шаблоны, и Unity 6.
2. Распакуйте архив. Папку `Scripts` (она лежит в `Assets`) перетащите в окно Project в Unity прямо на папку `Assets`. Можно и просто скопировать её в папку `Assets` проекта через проводник.
3. Дождитесь компиляции (крутится значок в правом нижнем углу). В окне Console (Window → General → Console) не должно быть красных ошибок.
4. Откройте любую сцену (например, `SampleScene`) и нажмите Play. Ничего добавлять в сцену не нужно: `GameManager` создаётся сам.

В окне Game лучше выбрать соотношение сторон 16:9.

## Управление

- WASD или стрелки: движение
- Пробел или левая кнопка мыши: стрельба (можно удерживать)
- R: начать заново после проигрыша

## Правила

- Красный круг даёт 10 очков. Оранжевый треугольник даёт 20 очков и летит «змейкой».
- Столкновение с врагом или пропущенный враг отнимают жизнь. Жизней три.
- Со временем враги появляются чаще и летят быстрее, максимум сложности через 90 секунд.
- Рекорд сохраняется между запусками.

## Что где менять

Во время Play выделите объект в окне Hierarchy (`GameManager`, `Player`) и меняйте числа в Inspector. Это удобно для настройки на глаз, но после остановки Play значения вернутся. Чтобы изменения остались, поправьте поля в начале `GameManager.cs` и `PlayerController.cs`.

- `GameManager`: число жизней, частота появления врагов, скорость роста сложности, отнимает ли жизнь пропущенный враг
- `PlayerController`: скорость корабля, скорострельность, время неуязвимости после попадания

## Что в каком скрипте

- `GameManager.cs`: камера, спавн врагов, счёт, жизни, интерфейс, перезапуск
- `PlayerController.cs`: движение, стрельба, столкновения корабля
- `Enemy.cs`: два вида врагов
- `Bullet.cs`: пуля и попадание по врагу
- `Starfield.cs`: фон со звёздами
- `SpriteFactory.cs`: рисует круг, квадрат и треугольник из кода
- `GameInput.cs`: ввод, работает и со старым Input Manager, и с новым Input System

Все классы лежат в пространстве имён `SpaceShooter`, так что с вашими скриптами они не конфликтуют.

## Если что-то пошло не так

- Красные ошибки в Console: скопируйте текст целиком и пришлите мне, я поправлю.
- Ошибка про `Rigidbody2D` или `Collider2D`: Window → Package Manager → Packages: Built-in → включите «2D Physics».
- Игра не появилась после Play: проверьте, что скрипты лежат внутри папки `Assets`, а в Console нет ошибок компиляции.

## Сборка готовой игры

File → Build Profiles (в старых версиях Build Settings) → Add Open Scenes → выберите платформу → Build.
