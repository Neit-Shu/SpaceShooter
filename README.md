# SpaceShooter

Прототип 2D-аркады на Unity: космический корабль двигается и стреляет, сверху падают враги. Есть счёт, три жизни, рекорд и перезапуск.

Игра целиком собирается из кода: спрайты рисуются программно, сторонние пакеты, префабы и настройка сцены не нужны.

## Как запустить

1. Создайте проект в Unity Hub: шаблон «2D (Built-In Render Pipeline)» или «Universal 2D». Подойдут и 3D-шаблоны.
2. Скачайте репозиторий (Code → Download ZIP) или склонируйте его.
3. Скопируйте папку `Assets/Scripts` в папку `Assets` вашего проекта (или перетащите её в окно Project в Unity).
4. Дождитесь компиляции. В окне Console не должно быть красных ошибок.
5. Откройте любую сцену (например, `SampleScene`) и нажмите Play. Добавлять что-либо в сцену не нужно: `GameManager` создаётся сам.

В окне Game удобнее всего соотношение сторон 16:9.

## Управление

- WASD или стрелки: движение
- Пробел или левая кнопка мыши: стрельба (можно удерживать)
- R: начать заново после проигрыша

## Правила

- Красный круг даёт 10 очков. Оранжевый треугольник даёт 20 очков и летит «змейкой».
- Столкновение с врагом или пропущенный враг отнимают жизнь. Жизней три.
- Со временем враги появляются чаще и летят быстрее, максимум сложности через 90 секунд.
- Рекорд сохраняется между запусками.

## Настройка

Основные параметры лежат в начале скриптов:

- `GameManager.cs`: число жизней, частота появления врагов, скорость роста сложности, отнимает ли жизнь пропущенный враг
- `PlayerController.cs`: скорость корабля, скорострельность, время неуязвимости после попадания

Во время Play их можно менять в Inspector (выделите `GameManager` или `Player` в Hierarchy), но после остановки значения вернутся к тем, что в коде.

## Устройство проекта

- `GameManager.cs`: камера, спавн врагов, счёт, жизни, интерфейс, перезапуск
- `PlayerController.cs`: движение, стрельба, столкновения корабля
- `Enemy.cs`: два вида врагов
- `Bullet.cs`: пуля и попадание по врагу
- `Starfield.cs`: фон со звёздами
- `SpriteFactory.cs`: рисует круг, квадрат и треугольник из кода
- `GameInput.cs`: ввод, работает и со старым Input Manager, и с новым Input System

Все классы лежат в пространстве имён `SpaceShooter`, поэтому не конфликтуют с другими скриптами проекта.

## Если что-то не работает

- Ошибка про `Rigidbody2D` или `Collider2D`: в Window → Package Manager → Packages: Built-in включите «2D Physics».
- После Play ничего не появилось: проверьте, что скрипты лежат внутри папки `Assets`, а в Console нет ошибок компиляции.
- Другая проблема: создайте Issue в этом репозитории и приложите текст ошибки из Console.

## Сборка игры

File → Build Profiles (в старых версиях Build Settings) → Add Open Scenes → выберите платформу → Build.
